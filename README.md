# Filee — Glassmorphism para macOS

Este projeto é um fork do [Filee](https://github.com/KnifeLemon/Filee), um conversor de arquivos gratuito e de código aberto.

Estou desenvolvendo um novo visual com estética **glassmorphism**, pensado para macOS, mantendo as funcionalidades de conversão do projeto original.

O novo visual está em desenvolvimento.
